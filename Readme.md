# `openrazer-rs`

Asynchronous bindings to the OpenRazer daemon, written in pure Rust. The API is
similar to the `openrazer` Python module. See [examples] to get started.

[examples]: ./examples

## Disclaimer

I started this crate to fulfill my own need: change lighting mode on my Razer
Huntsman keyboard. This keyboard is the only Razer device I have and can test
this crate on. This crate's structure is meant to be easily extended though,
so if it doesn't work well with your device, come and submit a merge request!
